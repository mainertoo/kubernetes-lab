# VolSync Restic → Kopia migration drivers (archived)

One-off scripts that drove the fleet migration described in
[`docs/volsync-kopia-transition.md`](../../../docs/volsync-kopia-transition.md).
The migration finished in May 2026 and the cluster is single-engine Kopia, so
these are kept for reference only. They target resources (the Restic policy and
its per-app Secrets) that no longer exist; do not run them.
